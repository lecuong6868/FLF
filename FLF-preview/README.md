# FLF-preview — mở offline

1. Giải nén `FLF-preview.zip`.
2. Mở `index.html` (chuyển tới `option-b/`) bằng Chrome / Edge / Firefox.

Không cần cài đặt hay chạy server.

**Tải gói:** xem một dòng trong `docs/URL-TAI.txt` tại gốc repo (URL raw GitHub theo nhánh, không chứa chuỗi hex).

Form liên hệ chỉ **minh họa** — chưa có backend, không báo gửi thành công giả.
